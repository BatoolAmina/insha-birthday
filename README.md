# Happy Birthday, Insha Fatima
Run: `npm install && npm run dev` — check: `npm run build && npm start`.

Add your media (nothing is invented; empty slots show labelled placeholders):
- Photos: public/media/photos/photo-1.jpg … photo-6.jpg
- Videos: public/media/videos/video-1.mp4, video-2.mp4
- Music: public/audio/birthday.mp3 (use a file you have the licence for)
- Duas: the supplied Arabic duas and Roman Urdu prayers are in `lib/content.js`.

The music player starts at full webpage volume. Use the phone or computer's hardware volume buttons to adjust device playback volume; the on-page slider can lower it. The birthday flow includes a firefly-catching game and a dua chapter with the supplied Arabic and Roman Urdu prayers.
